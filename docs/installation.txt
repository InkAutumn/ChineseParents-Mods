中国式家长 十合一模组合集 · 2026-10-12

一、适用版本
Windows Steam版《中国式家长》，Steam Build 24710774，游戏显示版本2.0.2.0，Unity 2022.3.62f3c1 x86 Mono。
仅上述构建经过验证。WeGame、移动版、其他系统和后续更新未验证，不能只凭版本号相似就覆盖。
包内已包含 BepInEx 5.4.23.5 x86 和针对此版游戏的 MonoMod 兼容修正；不需要安装 .NET SDK 或编译工具。

二、安装（游戏必须已退出）
1. 先完整解压压缩包，不要在压缩包窗口中直接运行检查。
2. Steam库中右键《中国式家长》→管理→浏览本地文件，打开含 game.exe 的文件夹。
3. 备份存档：在资源管理器地址栏输入 %USERPROFILE%\AppData\LocalLow\moyuwan\chineseparentsgame，将整个 Save 文件夹复制到游戏目录之外的安全位置。
   如有 %USERPROFILE%\AppData\LocalLow\com.moyuwan.chineseparents，也一并备份；Steam安装目录 userdata 下对应账号的736190目录可另行备份。新玩家尚无存档时可跳过。
4. 双击 Check-Compatibility.cmd，在弹出窗口选择上面含 game.exe 的游戏目录。工具只读取和校验，不会安装、联网或修改存档。
   看到“PASS / 检查通过”才继续；失败时不要强行覆盖。检查同时核对原版文件、发行包内容和已有同名文件。
5. 打开包内“复制到游戏根目录”，将里面的 BepInEx 文件夹、winhttp.dll、doorstop_config.ini 和 .doorstop_version 复制到含 game.exe 的目录。
   注意：复制的是里面的内容，不是把“复制到游戏根目录”这个外层文件夹放进去。
   已有相同文件可以跳过；已有不同版本的加载器或其他插件时，请先处理检查报告的冲突，不要直接选择全部替换。
6. 按平常方式从Steam启动游戏。十个模组默认开启。首次启动后会在 BepInEx/config 生成各自配置。

三、只安装部分功能
从全新游戏环境安装时，复制上述加载器及 BepInEx/core，但只从 BepInEx/plugins 选择需要的模组文件夹复制。
每个模组一个独立文件夹，各功能互不依赖；加载器与兼容修正必须保留。
如果已全部安装，更简单的方式是退出游戏后关闭不需要的配置。
各模组的文件名、配置路径与使用方法在“模组说明”文件夹。
不要重复放置同一个模组DLL；旧 ChineseParents.Mod.dll 是早期版本，不应与 GuaranteedSpecialties 同时加载。

四、关闭与卸载
临时关闭：退出游戏，在对应 .cfg 中把 [General] 下 Enabled = true 改为 Enabled = false，保存后重启。
除“气运传家宝”外，卸载某功能可在退出游戏后，将 BepInEx/plugins 下对应模组文件夹移到游戏目录之外。配置可保留。
关闭/卸载不会撤销已经获得的零钱、属性、特长或已经提交的下一代。如需撤回进度，请使用此前备份。

“气运传家宝”特别说明：
存档曾购买、携带或使用气运内容后，必须保留 FortuneHeirloom/ChineseParents.FortuneHeirloom.dll。
不用时设 Enabled = false，保留存档识别新增内容所需的定义。不要直接删DLL或停用整个加载器后继续读取此类存档。
要彻底卸载，请先恢复使用气运内容之前的整套存档和账号数据，再移走该模组。

完全移除本合集：先满足上面的存档条件，再移走十个模组文件夹。
如果BepInEx仅为本合集安装且没有其他模组依赖，先把 BepInEx/LifeSimulatorBackups 复制到安全位置，再将 BepInEx、winhttp.dll、doorstop_config.ini、.doorstop_version 移到游戏目录之外。
如果之前已有加载器，请恢复安装前的加载器备份，保留其他模组需要的文件。
Steam“验证文件完整性”通常不会移除额外添加的模组文件，不能代替上述卸载。

五、常见情况
首富之子：调整的是每回合零花钱收入下限，不是钱包余额；商店系统未开放时不提前发钱。
模拟人生：主线完成取名后，按钮在名字右侧。预览取消不提交；确认进入下一代会保存结果，备份在 BepInEx/LifeSimulatorBackups。
气运：需在原传家宝界面花200学费购买并携带，才解锁娱乐中的气运修炼。
脑洞：等约0.32秒的翻牌动画结束后再点击格子。
功能未出现：确认文件没有套了两层目录；查看 BepInEx/LogOutput.log 是否出现对应模组的加载记录；确认 Enabled = true。
游戏更新后检查失败：先等待适配，不要把这个兼容补丁套用到其他Unity/Mono版本。
与第三方模组的组合未逐一验证；尤其不要同时安装修改相同机制的旧版补丁。
反馈时提供游戏构建、模组版本、复现步骤和报错截图；日志中可能有本机路径，分享前可自行遮去个人信息。

六、发行内容
本合集仅分发模组及所需运行环境，不包含游戏本体、游戏原始程序集、玩家存档、账号文件或测试插件。
第三方运行库的许可证、来源及Doorstop对应源码见“第三方许可”；无需复制该文件夹到游戏目录。
此包未附开发工作区脚本；玩家不需要原作者的磁盘路径或本地开发环境。
